  instead (157 tests, all pass). No file was changed.

  (launched at `b8feeca`, run concurrently), I pushed interim commits holding finished
  result folders while the other runs were still going. The harness reads `HEAD` when it
  writes the manifest at the end of a run, so those three manifests recorded later commits
  (`11aeb41`, `9a2f43a`, `d5285d9`), which differ from `b8feeca` only by added files under
  `paperC/results/`. To give every manifest the commit at which the inputs were read, I
  re-ran the three FR-AF samples in a clean worktree of `b8feeca` and committed those
  outputs. For each re-run, `runs.csv`, `controls.csv` and `summary.md` are byte-identical to the first run's files and only `manifest.json` changed (its `harness_commit` field and the output hashes it lists). The committed four files of every sample match the hashes of both CTRL-DET clones.

  `HEAD`. I ran it from a detached worktree at `b8feeca` so that the clones are at the
  commit where the committed outputs were produced and the manifest hashes can be
  compared to the committed files. Each `determinism.json` records commit `b8feeca`.
