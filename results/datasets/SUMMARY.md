## DMN TCK decision tables

TCK tables test engines, not completeness: gaps and overlaps are often intended (for example, a FIRST or PRIORITY table relies on overlaps). They are reported, not judged. Domains follow `dmn_import` I-D1 to I-D3: a string input without declared values gets the sentinel `<other>`, a number without inputValues is unbounded, and numbers are real-valued (D-1), so a gap such as (9..10) counts even if the input only ever takes integers; the count in brackets is such integer-free regions. The oracle runs on the exact domain when it is finite, otherwise on a bounded integer proxy of the unbounded inputs (which keeps every elementary cell).
